# 🎓 CampusBuddy – AI College Assistant

## 📌 Project Overview

CampusBuddy is an AI-powered college assistant developed using JavaScript, Node.js, LangChain, Groq API, and SQLite.

It helps students and faculty access college-related information through a simple conversational interface. Users can ask questions about attendance, fee status, marks, and student records.

The project uses an AI agent and database tools to retrieve information from the college database.

## 🎯 Objectives

* Provide quick access to student information.
* Check student attendance and attendance percentages.
* Retrieve fee payment status.
* Access student marks and report cards.
* Help faculty identify students with attendance shortages.
* Provide a simple, interactive AI-based college assistant.

## 🛠️ Technologies Used

* **JavaScript** – Application programming
* **Node.js** – JavaScript runtime environment
* **LangChain** – AI agent and tool integration
* **Groq API** – Large Language Model integration
* **SQLite** – Database management
* **dotenv** – Environment variable management
